Sobre

Desenvolvedor backend com atuação focada em integração de sistemas e automação de processos empresariais. Minha experiência central está em conectar plataformas distintas ERPs, sistemas internos e APIs de terceiros através de soluções técnicas consistentes e de fácil manutenção.

Tenho capacidade de analisar requisitos de negócio, mapear fluxos operacionais e traduzir essas necessidades em código funcional. Trabalho bem tanto em contextos exploratórios onde o problema ainda não está totalmente definido quanto em demandas estruturadas com escopo claro.

Priorizo código legível, documentado e orientado à manutenibilidade. Tenho familiaridade com ambientes Linux, ferramentas de versionamento e containerização básica com Docker.

Integração de Sistemas

Consumo e documentação de APIs REST, autenticação OAuth/token, parsing de JSON e XML, e criação de camadas de integração entre sistemas heterogêneos.

Automação de Processos

Scripts Python para automação de tarefas repetitivas, processamento de arquivos e geração de relatórios estruturados a partir de fontes de dados diversas.

Análise de Requisitos

Tradução de regras de negócio complexas em especificações técnicas implementáveis, com foco em sistemas financeiros, fiscais e operacionais.

Dados Estruturados

Projetos

🔗
Integração ERP

Automação de Faturamento via API Omie

Problema

Processo manual de criação de pedidos e geração de NF-e consumia horas diárias da equipe financeira, com alta incidência de erros de digitação e retrabalho.

Solução

Integração com a API REST do ERP Omie para automatizar a criação de pedidos de venda, consulta de clientes e emissão de notas fiscais. A partir de dados estruturados em JSON, o script executa todo o fluxo de faturamento sem intervenção manual.

↑ Redução de ~70% no tempo de emissão
Python REST API JSON Omie ERP NF-e
📄
Processamento de Dados

Parser de XML para Extração de NF-e

Problema

Arquivos XML de notas fiscais eram processados manualmente, tornando a conciliação fiscal demorada e sujeita a erros de interpretação da estrutura do documento.

Solução

Desenvolvimento de um parser em Python utilizando ElementTree para extração sistemática de campos-chave (emitente, destinatário, itens, impostos, chave de acesso) com saída em CSV e JSON para consumo por outros sistemas.

↑ Processamento de lotes sem intervenção manual
Python XML ElementTree CSV ETL

Automação de Processos

Pipeline de Sincronização entre Sistemas

Problema

Dados de clientes e pedidos precisavam ser replicados entre dois sistemas internos sem uma integração nativa, exigindo exportação e importação manual de planilhas.

Solução

Script Python agendado que consome a API do sistema de origem, normaliza os dados, e insere ou atualiza registros no sistema de destino via API REST. Inclui log de erros e controle de idempotência para reprocessamento seguro.

↑ Eliminação de processo manual diário
Python REST API MongoDB Cron Logging

Backend · Dados

Relatório Automatizado de Indicadores

Problema

Relatórios operacionais eram gerados manualmente a partir de múltiplas fontes, dificultando a visibilidade rápida de métricas e atrasando decisões gerenciais.

Solução

Consolidação de dados via queries SQL e chamadas à API do ERP, processamento com Python e geração automatizada de relatório estruturado entregue por e-mail em horário configurável.

↑ Relatórios diários sem interação humana
Python SQL smtplib REST API Automação
